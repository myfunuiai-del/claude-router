🗑️ Uninstall C-Router

Are you sure you want to uninstall C-Router? This will:

  • Stop the C-Router proxy server (port 8999)
  • Remove the Auto-Start hook from ~/.bashrc
  • Delete CLI commands (crouter, croute)
  • Delete ~/.gemini/claude-router & all configs

⚠️ FINAL CONFIRMATION (Step 2/2)

All C-Router files, provider keys in config.json, and symlinks will be permanently deleted. This cannot be undone.
